## 🌟 Sobre o Projeto & Conceito Artístico

Acredito que programar e criar arte compartilham a mesma essência: ambas as disciplinas transformam uma tela em branco em uma experiência significativa. Inspirada na obra e na paleta de cores das telas de **Vincent van Gogh**, estruturei este portfólio para refletir a harmonia entre:

* **Tecnologia:** Estrutura sólida, código limpo e navegação fluida.
* **Arte:** Design responsivo, experiência do usuário e harmonia visual imersiva.
